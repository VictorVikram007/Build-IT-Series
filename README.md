# Portfolio Website - Vikram Balaji

A modern and responsive portfolio website showcasing my expertise in AI, Machine Learning, and Full Stack Development.


## 🛠️ Built With
- HTML5
- CSS3 (Custom Animations)
- JavaScript (ES6+)
- Bootstrap 5
- Git

## 📋 Features
- Responsive Design
- Interactive UI Elements
- Project Showcase
- Skills Progress Bars
- Contact Form
- Smooth Animations
- Dark/Light Theme Toggle

## 🗂️ Project Sections
1. **About**: Professional background and introduction
2. **Projects**: Showcase of key projects including:
   - WearX - Smart Wearable Device
   - Landmark Detection System
   - AI Traffic Management System
3. **Skills**: Technical expertise visualization
4. **Experience**: Professional timeline
5. **Contact**: Get in touch form

## 💻 Installation

1. Clone the repository
```powershell
git clone https://github.com/VictorVikram007/portfoliio.git
```

2. Navigate to project directory
```powershell
cd portfoliio
```

3. Open `index.html` in your browser or use Live Server in VS Code
